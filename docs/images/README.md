# Ivaldi launch images

The desktop and Android campaign images use the built-in image generation tool with actual Ivaldi screenshots as references. They are promotional compositions; the original captures are also included.

- `ivaldi-desktop-review.png`: production web UI displaying a real OpenCode session, tool calls, and the working-tree diff for the Atlas demo.
- `ivaldi-android-session.png`: signed Android 1.20.1 APK on an Android 15 emulator, connected to the same demo server.
- `ivaldi-desktop-campaign.png`: desktop promotional composition.
- `ivaldi-android-campaign.png`: Android promotional composition.

The demo used OpenCode's Big Pickle model to create a reading-list app, add keyboard shortcuts, run a syntax check, and review accessibility. No conversation messages or code changes were fabricated for the screenshots.

## Desktop prompt

Use case: ads-marketing
Asset type: Ivaldi product launch image for GitHub README, landscape 16:9.
Input image 1 is the REAL Ivaldi application screenshot and must be the central product. Build a premium editorial software advertisement around it. Preserve the screenshot exactly: its text, code, icons, panel structure, colors and controls. Do not invent or redraw a different UI. Place this screenshot as a large straight-on flat application window occupying the lower 75% of the artwork, sharp and legible, very subtle corner radius and fine silver edge. No laptop mockup. No exaggerated perspective. Frame it against a restrained charcoal studio background with a subtle warm silver light at the edges and an extremely faint blue glow under the window. Dark neutral visual language.
At top left exact large tasteful text "Ivaldi". At top right exact concise copy "Watch the work. Review the changes." in refined light gray sans-serif. Clean hierarchy, generous but not excessive margins. The actual populated UI must dominate and look beautiful. No floating fake feature cards, no badges, no added claims, no watermark. Publication-ready high resolution product campaign.

## Android prompt

Use case: ads-marketing. Wide 16:9 Ivaldi mobile product campaign, polished and restrained.
Input image is an actual Android screenshot showing a real agent's completed work. Preserve its visible content, text, icons, colors and layout. Place the screenshot, straight-on and legible, inside one elegant slim Android phone with rounded dark graphite metal edges on the right half. No invented screen or added app controls. Show the whole phone with generous breathing room, height about 88% of frame.
Left half: large refined white sans-serif text exactly "Your workspace." and next line "Within reach." Small wordmark "Ivaldi" above. Below, smaller text exactly "Follow the work from Android." Lots of calm negative space with precise alignment.
Dark charcoal background matching the app, subtle studio silver light near floor, slight soft shadow beneath phone, very restrained blue edge reflection. Expensive editorial software advertisement. No other objects, no flashy gradients, no badges, no fake UI, no extraneous text, no watermark. The app must remain recognizable and its coding activity visible.
