# Quality review, October 2026

This is the issue list from a hands-on review of the desktop and web app on branch `codex/mobile-preview-2`. I ran an isolated server against a throwaway data folder and a demo git repo, drove the UI in a headless browser at 1440x900 in Developer and Work mode, and had the agent make a real edit. Review agents read the server, UI state, styling, and the React Native app.

Each row has a status. `open` means not started. `fixed` means changed and validated. `partial` means some of the planned fix landed. `needs decision` means the fix depends on a product call. `decided` means a product call kept the behavior. `deferred` means out of scope for this pass. `not reproduced` means the claim did not hold up when checked. On finished rows, the fix column says what changed.

Rows marked "seen live" were reproduced in the running app. The rest come from code reading.

## Security

These come first. The desktop backend listens on fixed port 57123 with no UI password by default, see `packages/electron/main.mjs:1595`, so every hole below is reachable from the user's own browser.
