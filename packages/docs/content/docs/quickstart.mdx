# Quickstart

## Fastest path

1. Follow [Install](/install/) to get an Ivaldi desktop build for an available platform or run the web app from source.
2. Open Ivaldi and connect your model provider.
3. Select a project or start a chat, send a message, and wait for the response.
4. To connect another device, follow [Connect devices](/connect-devices/).

Desktop includes OpenCode. The web and VS Code runtimes require a separate OpenCode installation. Protect a web instance with a strong UI password before exposing it beyond your computer.

If the page doesn't load, check [Troubleshooting](/troubleshooting/).

## Which app should I use?

- use **desktop** for day-to-day work on a platform listed in the Ivaldi release
- use **web** for remote access and reviewing from your phone
- use **VS Code** for sessions right next to your code
